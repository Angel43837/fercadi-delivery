# Sesión 2026-07-29 — Miércoles

## Resumen del día

Se corrigió una brecha de seguridad real (el código de Admin estaba filtrado dentro del binario de GOGO Food, además de existir en su app separada), y se separó **GOGO Flota** en su propia app — mismo patrón que Admin: entry point Dart propio, flavor de iOS propio, APK de Android propio y sitio web propio.

---

## Lo que se hizo

### Hallazgo: Admin estaba duplicado dentro del router del cliente
- `lib/router.dart` (usado por `main.dart`, la app cliente) todavía tenía registradas `/admin` y `/admin-login`, con `AdminScreen`/`AdminLoginScreen` importadas — a pesar de que `main_admin.dart` ya existía como app separada
- Esto significaba que el código de Admin **sí se compilaba dentro del APK/IPA de GOGO Food**, aunque estuviera gateado por un `redirect` en tiempo de ejecución (no es una barrera de seguridad real, solo evita la navegación normal)
- Se quitó `/admin` y `/admin-login` de `router.dart` — Admin ahora vive exclusivamente en su propio binario

### GOGO Flota — separada en su propia app
- **Antes:** `/flota-login` y `/flota` vivían dentro del router compartido del cliente, igual que tenía Admin (mismo problema)
- **Ahora:** `lib/main_flota.dart` nuevo — entry point Dart propio, su propio `GoRouter` (solo `/flota-login` y `/flota`), sin nada del cliente
- Se quitaron esas rutas y sus imports de `router.dart`, y se limpiaron las referencias a `admin`/`jefe_flota` en `_roleHome()`, el bloqueo de rutas por rol, `splash_screen.dart`, `login_screen.dart` y `auth_service.dart` (todas apuntaban a `/admin` o `/flota`, rutas que ya no existen en ese router)

### iOS — flavor "flota" (mismo patrón que Admin)
- Nuevo flavor en Xcode: `Debug-flota` / `Release-flota` / `Profile-flota`, bundle id `com.fercadi.flota`
- Archivos nuevos: `ios/Runner/Info-Flota.plist` (nombre "GOGO Flota", esquema `fercadiflota://`), `ios/Flutter/*-flota.xcconfig`, scheme `flota.xcscheme`
- `ios/Podfile` — mapeo de las 3 configs de flota agregado
- Se usó el gem `xcodeproj` (Ruby) para clonar las configuraciones de "-admin" a "-flota" en los 4 targets del proyecto (Runner, RunnerTests, GOGOTrackingWidgetExtension, y a nivel de proyecto), con respaldo de `project.pbxproj` antes de tocar nada

### Bug encontrado y corregido: bundle id del widget mal prefijado
- Al compilar el flavor de flota apareció: *"Embedded binary's bundle identifier is not prefixed with the parent app's bundle identifier"*
- Causa: el widget de pantalla de inicio (`GOGOTrackingWidgetExtension`) tenía el bundle id fijo `com.fercadi.app.GOGOTrackingWidget` en **todas** las configuraciones, incluyendo las de Admin y Flota — pero un binario embebido necesita estar prefijado por el bundle id de la app que lo contiene
- Este bug ya existía para Admin (nunca se había notado porque nadie había compilado esa combinación hasta ahora)
- **Fix:** `com.fercadi.admin.GOGOTrackingWidget` para las configs de admin, `com.fercadi.flota.GOGOTrackingWidget` para las de flota
- Se verificó compilando los tres flavors (`flutter build ios --no-codesign` para cliente, admin y flota) — los tres compilan limpio

### Web — GOGO Flota también necesita su propio sitio
- El jefe de flota usaba el panel desde `web-iota-brown-32.vercel.app/flota-login` (el mismo sitio del cliente) — al sacar esas rutas del router del cliente, ese acceso se hubiera roto
- Se decidió (con el usuario) darle también su propio sitio web: `flutter build web --target lib/main_flota.dart` a una carpeta de salida separada (`build/web-flota`)
- Esto además resuelve de raíz un problema viejo documentado (sesión de Supabase del jefe de flota interfiriendo con la sesión del cliente en el mismo navegador) — al ser otro dominio, ya no comparten `localStorage`
- **Pendiente:** desplegar `build/web-flota` a un proyecto de Vercel separado — no se hizo desde esta Mac porque la cuenta de Vercel logueada aquí no es la correcta (mismo problema ya documentado el día anterior); se deja para cuando se use la cuenta correcta

### `build_apks.ps1`
- Se agregó una tercera invocación para generar `GOGOFlota.apk` (`FLUTTER_APP_ID = com.fercadi.flota`, `--target lib/main_flota.dart`)

### Documentación actualizada
